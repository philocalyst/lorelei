## What exists

`bough::typed`: a façade element value converts to an element-layer value and drives `World<Ty<V>, Canvas>`
through `bough-x`'s own sinks. No node tree, no boxed handler, no `dyn Any`: boxes are `bough_lay::LBox` with one
record (`PBox`), one-line text is a record naming a shaped run (`PLine`), a word-sized `sig!` operand is the block
word at the field's proven offset (`Dy`), `hover_bg` is a selection on a hidden hover word (`HSel`), handlers are
typed components that reach their owner by type (`Root`, `InList<T>`), `.scroll` and `list(..)` are a space moved
by the offset's word with rows by exposure. Admission is per root view, at compile time (specialisation:
`MaybeTyped`), plus named run-time refusals (a wrapped paragraph, a non-viewport list, a 48th bound word); a view
that is not admitted is Card 3's `bough::lower`. Converted so far: `div`/`row`/`column`/`block` without reactive
box operands, `text`/`label`, `button`, `hover_bg`, `on_click`/`on_press`/`on_hover`/`on_key`/`on_drag`,
`focusable`, `.scroll`, virtual `list`. Not converted (fallback): `each` and `Vec` children, `para`, `image`,
`.opacity`/`.translate`/`.w_op`/`.h_op`, everything Card 3 refuses.

## Where the 115,022 goes (measured, `typed::App::profile`)

Running the view and converting its fixed part with no sink: **8,927**. A whole re-description of an unchanged
view: **115,022**. So conversion of the fixed part is 8 % and the world's re-description pass is the rest: the
heap layout of the root's words, and for each of about 20 exposed rows a conversion (four run lookups by string
hash, each through a `RefCell` and two hash tables, and a baseline computed from the face's tables) followed by
a compare that finds nothing. Not yet split further; that split is the first thing the next step owes.

The lesson is the owner's: this number is a cost that follows the scene for a change that is one word, and
making the row conversion cheaper would be tuning. Every cell above that re-describes is a cell whose change has
not been put in the basis where it is one word.
